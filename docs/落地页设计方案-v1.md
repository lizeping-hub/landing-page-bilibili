# 哔哩哔哩品牌体验落地页 · 设计方案 v1.1

日期：2026-10-11

状态：已完成首版并发布至 [GitHub Pages](https://lizeping-hub.github.io/landing-page-bilibili/)。自动构建、资源预算和部署均通过，线上关键交互与 PNG 下载已复核，等待用户体验反馈。

项目定位：面向访客的 B 站品牌体验单页，同时作为 AI 产品经理的 AI 协作设计与执行作品。

## 1. 目标与已确认的设计选择

访客通过发现兴趣、体验弹幕、支持创作、生成兴趣名片，感受 B 站的内容与社区特点。面试展示聚焦产品理解、界面设计、AI 协作、技术学习和性能取舍。

用户已确认：

- 全站中文，只有一个页面，所有体验均留在本页。
- 全局采用 #131829 深色基底，主色 #FB7299，辅助赛博蓝 #00AEEC；轻度霓虹与像素断角强化二次元、极客气质。
- 五段框架：热爱登场 → 兴趣探索 → 弹幕共鸣 → 热爱被看见 → 兴趣名片。
- “卡片舞台”排版：首屏左侧文字、右侧小电视与内容卡片。
- 统一制作概念封面和插画短片；保留柔和空间感、光影与景深，调整素材以匹配深色霓虹环境。
- 桌面设计基准为 1440 × 900 CSS 像素；视口宽度小于 768px 时切换为移动端纵向流式布局。
- 兴趣区采用自然纵向滚动、CSS sticky 背景与 Y／Z 轴发牌堆叠；移除横向滚动和滚轮／触控板拦截。
- 兴趣最多选三个；弹幕最多 20 个字；支持点赞、投币、收藏反馈。
- “入站档案”包含可修改昵称、兴趣和一句弹幕，可保存 PNG；未完成前序互动也能生成默认档案。
- 后续开源到 GitHub，通过 GitHub Pages 域名访问。

本稿以 2026-10-11 的重构要求为准，更新移动端降级、暗黑品牌色、纵向发牌、首屏启动、弹幕粒子和网感文案。文末附三个可复用核心代码片段；既有五段框架、兴趣数量、弹幕字数、视频预算和 PNG 导出能力延续。

## 3. 桌面设计、移动端适配与 Auto layout（P0）

### 布局参数

| 项目 | 参数 |
| --- | --- |
| 设计基准 | 浏览器可视区域 1440 × 900 CSS 像素 |
| 验证窗口 | 桌面 1280 × 720、1440 × 900、1920 × 1080；移动端 375 × 812、390 × 844；断点 767、768px |
| 主内容宽度 | 最大 1200px，居中；桌面最小左右留白各 48px |
| 栅格 | 12 列参考栅格；主要双栏采用约 5:7 或 6:6 比例；卡片间距约 24px |
| 首屏高度 | 跟随可视高度，并保证标题、主视觉和按钮同时可见 |
| 页面长度 | 桌面暂按约 8–9 屏设计，兴趣发牌段约 3.5 屏；移动端依卡片和文案自然展开，按最终素材修正 |
| 兴趣段 | 桌面舞台 position: sticky，top 为导航高度；外层提供自然纵向滚动距离；移动端取消 sticky、堆叠与长滚动留白 |
| 其余段落 | 按内容自然展开；观影段约 1.2 屏，其他段落约 1 屏 |
| 字号 | 首屏标题基准 88px，随窗口约 72–96px；章节标题约 48–64px；正文 16–18px；标签与控件 14–16px |
| 留白 | 8px 间距体系；章节上下留白约 96–128px |

采用 CSS Grid／Flex、最大宽度和弹性字号。宽度小于 768px 时，所有双栏与卡片容器均改为 display: flex、flex-direction: column，卡片恢复静态位置、完整宽度、正常透明度与可操作状态。移动端留白约 20px，输入字号至少 16px。

通过 gsap.matchMedia() 的条件判断管理全部复杂 GSAP 动效。切换到移动端、视口高度小于 640px 或请求减少动态效果时，自动 revert 本页动画和 ScrollTrigger、恢复内联变换，并清理卡片 inert／aria-hidden 状态。组件卸载时再次执行统一清理，覆盖 React StrictMode 的重复挂载。首屏内容和档案生成始终可用。

页面使用自然滚动；不捕获滚轮、不调用 preventDefault 拦截触控、不锁 body 滚动，也不使用 GSAP pin 创建滚动固定占位。

## 4. 视觉与素材（P1）

### 视觉规范

- CSS 主色令牌：--primary-color: #FB7299；辅助色：--secondary-color: #00AEEC。
- 全局基底：--bg-color: #131829；分层表面约 #1C2238；主要文字约 #F4F7FF。
- 柔和空间感插画结合粉蓝边缘光、霓虹线条和二次元兴趣符号。
- 小电视以浅色主体、粉色主光和赛博蓝辅助光建立统一形象。
- 卡片圆角基准 12px，以断角边框、小范围霓虹阴影和像素粒子增加极客线索；控制发光面积与阴影半径。
- 中文正文优先使用系统字体；统一字号、字重和行高，控制字体下载负担。
- 大标题与操作控件保持清晰对比；装饰卡片避开正文与按钮。

### 首版素材范围

1. 一套柔和空间感小电视主视觉及必要分层元素。
2. 六张统一风格概念封面：
   - 科技：“好奇心研究所”。
   - 知识：“原来如此”。
   - 动画：“想象力放映室”。
   - 游戏：“下一关，见”。
   - 音乐：“下一站，音乐现场”。
   - 生活：“日常值得记录”。
3. 三组概念创作者与作品信息：“像素实验室”“周末音浪”“日常观察员”，界面标注“概念创作者”。
4. 一支约 12 秒插画短片、一张静态视频封面。
5. 一套深色入站档案版式及可复用的背景、兴趣符号。

素材制作采用统一风格参考、AI 辅助插画生成和人工筛选调整。视频由自制分层插画离线合成与压缩，空间感主要包含在图片和视频素材中。

### 短片分镜

| 时间 | 场景 | 画面与运动 |
| --- | --- | --- |
| 0–4 秒 | 好奇心研究所 | 小电视进入知识空间；星球、实验装置和知识符号分层出现，镜头缓慢推进。 |
| 4–8 秒 | 下一站，音乐现场 | 场景沿卡片切换进入舞台；灯光、音符与创作设备产生柔和节奏。 |
| 8–12 秒 | 生活藏着小惊喜 | 镜头进入城市日常，光影和生活元素展开；结尾回到小电视，衔接开头。 |

目标参数：1280 × 720、24 帧／秒、约 12 秒、无声循环、可暂停。优先使用兼容性明确的 MP4 播放版本；单个播放版本下载预算不超过 3MB。其他编码版本按实际压缩和兼容验证结果补充，访客只加载所需版本。

## 5. 动效与交互规则（P2）

### 动效

| 位置 | 动效 | 初始参数 |
| --- | --- | --- |
| 首屏入场 | 极客终端日志启动，随后粉色闪光与主视觉散开 | 桌面首次挂载约 1.5 秒；日志使用预先排版的文本；移动端／减少动态模式直接呈现首屏 |
| 鼠标视差 | 主视觉与卡片产生轻微层次位移 | 约 4–8px，平滑跟随 |
| 首屏至兴趣区 | 小电视视线引导进入兴趣雷达 | 自然纵向滚动 |
| 兴趣区 | sticky 背景上六张卡片沿 Y／Z 轴发牌，已出现的卡片后移堆叠 | CSS perspective 约 1200px，初始 Z 约 -700px，Y 约 180px；按自然滚动进度推进 |
| 兴趣选择 | 标签高亮，卡片内侧选择标记更新 | 约 200–300ms；选择反馈放内层，避免覆盖外层发牌 transform |
| 观影区 | 同一深色基底上呈现视频舞台与边缘光 | 约 600–900ms |
| 弹幕 | 画面内从右向左移动 | 每条约 7–10 秒，3–4 条轨道，同时显示数量上限 8 条 |
| 弹幕 Hover | 内层文字放大至 1.15 倍、加粗并提高层级 | 外层负责移动，内层负责 Hover；避免两种 transform 互相覆盖 |
| 弹幕提交 | 输入框上方独立 Canvas 像素粒子散射 | 约 550ms；桌面最多 24 粒子，移动端最多 14；DPR 上限 2；快速连续提交替换前一次效果 |
| 创作者切换 | 作品和介绍协同切换 | 约 250–400ms |
| 点赞等反馈 | 图标、颜色和轻微缩放反馈 | 约 150–300ms |
| 档案呈现 | 昵称、雷达频段与弹幕组成入站档案 | 约 500–700ms；生成中按钮显示“进度保存中...” |

CSS sticky 与原生纵向滚动组合。卡片舞台不建立第二个滚动容器；外层和祖先不设置阻断 sticky 的 overflow: hidden／auto。未激活的堆叠卡片设置 inert 与 aria-hidden，兴趣标签保持独立可操作；恢复流式布局时还原所有卡片状态。

首屏启动层仅负责视觉呈现，pointer-events: none、aria-hidden: true，不等待网络素材，不锁页面滚动，严格在约 1.5 秒内结束。离开视口的循环运动暂停；页面失去焦点时暂停视频和弹幕。粒子 Canvas 不参与档案导出；效果结束、窗口变化、页面隐藏或组件卸载时取消 RAF、移除监听并清空画布。

### 互动规则

- 兴趣：最多三项，可取消。选择第四项时提示“最多选择三个兴趣”，保持已有选择。
- 弹幕：最多 20 个可见字符，中文、标点计入，表情按可见字符统计；空内容不能发送；输入区显示剩余数量。发送后文字立即进入本页画面，并成为名片默认文案。支持键盘提交，中文输入法组字过程不触发提交。
- 弹幕开关：关闭时隐藏弹幕；开启时恢复当前体验。预设弹幕与访客弹幕共同构成演示氛围。
- 创作者：三组示例内容可在本页切换；点赞、投币、收藏可切换状态，反馈在本次体验内有效。
- 入站档案：默认昵称“热爱探索者”，最多 12 个可见字符；可修改昵称和档案文案。兴趣按当前选择显示。
- 默认档案：未选择兴趣时展示“好奇心”；未发送弹幕时使用“每一份热爱，都有回响。”。
- 导出：生成 1080 × 1350 PNG；预览和导出从同一 CSS 设计令牌读取粉蓝配色；按钮生成中显示“进度保存中...”并防止重复提交，完成后恢复可操作，失败时给出可重试反馈。
- 重新探索：清空本次昵称编辑、兴趣、弹幕和互动选择，回到首屏。
- 会话保存：兴趣、昵称、名片文案与互动状态保存在当前页面会话中，刷新可以恢复；滚动位置与临时运动状态按页面正常行为处理。

这些互动由页面本地数据驱动，作为产品体验演示。所有操作均留在本页。

## 6. 技术与部署方案

| 用途 | 选择 | 原因 |
| --- | --- | --- |
| 页面与状态 | React＋TypeScript | 统一组织五段页面、兴趣、弹幕、创作者与名片状态；明确数据边界 |
| 开发与构建 | Vite | 输出静态资源，便于本地预览和 GitHub Pages 部署 |
| 布局与样式 | CSS Grid／Flex＋项目样式变量 | 精细控制品牌版式与桌面自动布局 |
| 滚动动效 | GSAP＋ScrollTrigger＋gsap.matchMedia() | 自然纵向进度驱动 Y／Z 发牌，CSS sticky 固定背景；移动端自动还原与卸载 |
| 视频 | 浏览器原生 video | 封面、播放、暂停、循环与按需加载 |
| 入站档案导出 | 独立 Canvas | 直接绘制高分辨率档案，与粒子画布分离，复用本地图片和字体参数 |
| 会话状态 | sessionStorage | 支持当前会话刷新恢复，与资源缓存分别管理 |
| 部署 | GitHub Actions → GitHub Pages | 构建静态产物并发布至 GitHub Pages 域名 |

初版业务由纯前端完成。依赖版本在进入开发时核对并锁定；视频、图片与必要图标作为项目资源打包。部署时按用户站点或项目站点配置正确的资源路径，并检查最终域名下的图片、视频、下载和章节锚点。

gsap.matchMedia() 能在媒体条件改变时自动还原其中创建的动画和 ScrollTrigger；本稿采用其条件判断满足移动端卸载要求。CSS sticky 负责背景固定，ScrollTrigger 只读取自然纵向进度。[GSAP matchMedia 官方文档](https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/)、[ScrollTrigger 官方文档](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)、[Vite GitHub Pages 部署文档](https://vite.dev/guide/static-deploy.html#github-pages)

浏览器原生视频与 Canvas 提供播放控制和图片合成能力。[MDN video 文档](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video)、[MDN Canvas 图片绘制文档](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Using_images)

## 7. 首次加载、缓存与运行性能

### 资源预算（开发目标）

| 项目 | 预算 |
| --- | --- |
| 首屏关键资源下载总量 | 不超过 1.5MB，包含脚本、样式和首屏必要图片 |
| 首次必要 JavaScript | 压缩传输体积目标不超过 300KB |
| 单个视频播放版本 | 不超过 3MB |
| 完整浏览页面的资源下载 | 目标不超过 6MB，按访客实际加载的一个视频版本计算 |

### 加载顺序

1. 先呈现品牌标识、标题、按钮与有固定尺寸的主视觉占位；桌面启动动画立即执行，首屏必要图片并行加载，动画不承担加载屏职责。
2. 访客接近兴趣区时准备后续卡片素材。
3. 进入兴趣区后择机准备观影区视频；观影区先显示已定尺寸的静态封面，视频具备播放条件后启动。
4. 创作者图和名片附加素材接近各自章节时加载；导出前确保所需素材解码完成。

图片优先采用适当尺寸的 WebP／AVIF 并保留必要兼容处理。图片、播放器和名片预留尺寸，减少载入时的布局移动。视频未准备好或自动播放未成功时，保留封面和可点击的播放入口；网络加载不阻断兴趣选择、弹幕输入与章节浏览。

### 缓存与更新

- 构建资源使用内容指纹文件名，内容改变时得到新地址。
- 浏览器 HTTP 缓存负责重复访问的资源复用；具体缓存有效期以部署服务实际响应为准。
- 页面中的加载顺序负责首次体验，会话存储负责访客选择；二者分别管理。
- 页面访问过程中使用同一份已解码素材；重复进入章节复用资源。

缓存帮助重复访问减少下载，首次体验仍依靠资源预算和加载顺序。[MDN HTTP 缓存说明](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Caching)

### 运行控制

- 动画优先使用 Y／Z 位移、缩放和透明度；仅桌面堆叠舞台保留必要的 GPU 合成层；霓虹阴影为静态或短时状态反馈。
- 高频运动与 React 的普通界面状态更新分别处理，避免每一帧更新整个页面。
- 弹幕限定数量、及时移除离屏元素；鼠标跟随统一调度。
- 页面离开视口或失去焦点时暂停循环运动；名片导出按需进行。
- 窗口变化后重新计算纵向发牌进度；小于 768px 时彻底还原复杂动画、sticky 舞台高度和卡片操作状态。

### 11.2 媒体条件清理、1.5 秒启动与 3D 发牌

终端日志可依次显示“[就绪] 兴趣雷达上线”“[同步] 热爱频段连接中”“[启动] 前方高能！”。启动层 aria-hidden="true"，不接收指针事件。gsap.matchMedia() 管理整段桌面复杂动效，宽度小于 768px 时自动还原；原生 sticky 提供背景固定，无 pin 或横向拦截。

```ts
import { gsap } from "gsap";
import { ScrollTrigger } from "gsap/ScrollTrigger";

gsap.registerPlugin(ScrollTrigger);

// DOM: .interests > .interest-sticky > .card-track > .interest-card
// 标签控件放在 card-track 外；选择反馈放在卡片内层。
// 启动层：.boot-overlay[aria-hidden="true"] 内包含 .boot-log。
export function initPageMotion(root: HTMLElement): () => void {
  const section = root.querySelector<HTMLElement>(".interests");
  const cards = section
    ? Array.from(section.querySelectorAll<HTMLElement>(".interest-card"))
    : [];
  const originalMode = root.getAttribute("data-motion");
  const mm = gsap.matchMedia();
  let introPlayed = false;
  root.dataset.motion = "flow";

  mm.add(
    {
      always: "all",
      desktop: "(min-width: 768px)",
      short: "(height < 640px)",
      reduced: "(prefers-reduced-motion: reduce)",
    },
    (context) => {
      const { desktop, short, reduced } = context.conditions!;
      if (!desktop || short || reduced) {
        root.dataset.motion = "flow";
        return; // 不创建任何复杂滚动动画；旧上下文已自动 revert。
      }

      if (!introPlayed) {
        introPlayed = true;
        const boot = root.querySelector<HTMLElement>(".boot-overlay");
        const visual = root.querySelector<HTMLElement>(".hero-visual");
        if (boot) {
          const logs = boot.querySelectorAll(".boot-log");
          gsap.set(boot, { display: "grid", autoAlpha: 1 });
          const intro = gsap.timeline();
          if (logs.length) {
            intro.from(logs, { autoAlpha: 0, y: 6, duration: 0.15, stagger: 0.12 }, 0);
            intro.to(logs, {
              x: (i: number) => (i % 2 ? 1 : -1) * (120 + i * 30),
              y: -60, z: 240, scale: 1.2, autoAlpha: 0,
              duration: 0.25, ease: "power3.in",
            }, 1.05);
          }
          if (visual) {
            intro.from(visual, { z: -180, y: 24, autoAlpha: 0, duration: 0.5 }, 1);
          }
          intro.to(boot, { autoAlpha: 0, duration: 0.2 }, 1.3);
          intro.set(boot, { display: "none" }, 1.5);
        }
      }

      if (!section || !cards.length) return;
      root.dataset.motion = "deck";
      gsap.set(section, { "--deck-height": `${(cards.length + 1) * 50}svh` });
      gsap.set(cards, {
        y: 180, z: -700, rotationX: 16, autoAlpha: 0,
        zIndex: (index: number) => index + 1,
      });

      const originals = cards.map((card) => ({
        card, inert: card.inert, ariaHidden: card.getAttribute("aria-hidden"),
      }));
      let active = -1;
      const activate = (index: number) => {
        if (active === index) return;
        active = index;
        cards.forEach((card, i) => {
          card.inert = i !== index;
          card.setAttribute("aria-hidden", String(i !== index));
        });
      };

      const deck = gsap.timeline({ defaults: { duration: 0.8, ease: "none" } });
      cards.forEach((card, index) => {
        deck.to(card, { y: 0, z: 0, rotationX: 0, autoAlpha: 1 }, index);
        cards.slice(0, index).forEach((previous, previousIndex) => {
          const depth = index - previousIndex;
          deck.to(previous, {
            y: -14 * depth, z: -80 * depth,
            scale: Math.max(0.84, 1 - depth * 0.035),
            autoAlpha: Math.max(0.2, 1 - depth * 0.18),
          }, index);
        });
      });
      activate(0);
      deck.eventCallback("onUpdate", () => {
        activate(Math.min(cards.length - 1, Math.floor(deck.time())));
      });
      ScrollTrigger.create({
        trigger: section,
        animation: deck,
        start: () => `top top+=${parseFloat(getComputedStyle(root).getPropertyValue("--nav-height")) || 72}`,
        end: "bottom bottom",
        scrub: 0.6,
        invalidateOnRefresh: true,
        // 没有 pin、horizontal、wheel 监听或滚动锁。
      });

      return () => {
        root.dataset.motion = "flow";
        originals.forEach(({ card, inert, ariaHidden }) => {
          card.inert = inert;
          if (ariaHidden === null) card.removeAttribute("aria-hidden");
          else card.setAttribute("aria-hidden", ariaHidden);
        });
        // GSAP 动画、ScrollTrigger 与内联变换由 matchMedia 自动还原。
      };
    },
    root,
  );

  return () => {
    mm.revert();
    if (originalMode === null) root.removeAttribute("data-motion");
    else root.setAttribute("data-motion", originalMode);
  };
}
```

### 11.3 弹幕提交的轻量 Canvas 粒子

仅在弹幕字数、空输入与输入法状态校验通过、弹幕成功加入页面后调用 burstBling。把返回的 stop 存入 React ref，组件卸载时调用。粒子不等待网络、不影响发送结果，不加入 PNG 导出画面。

```ts
const runningBursts = new WeakMap<HTMLCanvasElement, () => void>();

export function burstBling(canvas: HTMLCanvasElement): () => void {
  runningBursts.get(canvas)?.(); // 连续提交替换旧效果，每个画布只保留一个 RAF。
  const reduced = matchMedia("(prefers-reduced-motion: reduce)");
  if (reduced.matches || document.hidden || !canvas.isConnected) return () => {};

  const ctx = canvas.getContext("2d");
  const { width, height } = canvas.getBoundingClientRect();
  if (!ctx || !width || !height) return () => {};

  const dpr = Math.min(window.devicePixelRatio || 1, 2);
  canvas.width = Math.round(width * dpr);
  canvas.height = Math.round(height * dpr);
  ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
  const style = getComputedStyle(canvas);
  const colors = [
    style.getPropertyValue("--primary-color").trim() || "#FB7299",
    style.getPropertyValue("--secondary-color").trim() || "#00AEEC",
  ];
  const count = matchMedia("(min-width: 768px)").matches ? 24 : 14;
  const particles = Array.from({ length: count }, (_, index) => {
    const angle = -Math.PI / 2 + (Math.random() - 0.5) * Math.PI;
    const speed = 110 + Math.random() * 150;
    return {
      x: width / 2, y: height * 0.8,
      vx: Math.cos(angle) * speed, vy: Math.sin(angle) * speed,
      size: 2 + Math.random() * 3, color: colors[index % colors.length],
    };
  });

  let raf = 0;
  let stopped = false;
  const startedAt = performance.now();
  let lastFrame = startedAt;
  function stop() {
    if (stopped) return;
    stopped = true;
    cancelAnimationFrame(raf);
    ctx!.setTransform(1, 0, 0, 1, 0, 0);
    ctx!.clearRect(0, 0, canvas.width, canvas.height);
    ctx!.globalAlpha = 1;
    document.removeEventListener("visibilitychange", onVisibility);
    window.removeEventListener("resize", stop);
    reduced.removeEventListener("change", onPreference);
    if (runningBursts.get(canvas) === stop) runningBursts.delete(canvas);
  }
  function onVisibility() { if (document.hidden) stop(); }
  function onPreference(event: MediaQueryListEvent) { if (event.matches) stop(); }
  function frame(now: number) {
    if (stopped) return;
    if (!canvas.isConnected || now - startedAt >= 550) return stop();
    const dt = Math.min((now - lastFrame) / 1000, 0.032);
    lastFrame = now;
    ctx!.clearRect(0, 0, width, height);
    ctx!.globalAlpha = 1 - (now - startedAt) / 550;
    for (const p of particles) {
      p.vy += 480 * dt;
      p.x += p.vx * dt;
      p.y += p.vy * dt;
      ctx!.fillStyle = p.color;
      ctx!.fillRect(p.x, p.y, p.size, p.size); // 小方块，像素 Bling。
    }
    raf = requestAnimationFrame(frame);
  }

  document.addEventListener("visibilitychange", onVisibility);
  window.addEventListener("resize", stop, { passive: true });
  reduced.addEventListener("change", onPreference);
  runningBursts.set(canvas, stop);
  raf = requestAnimationFrame(frame);
  return stop; // 组件卸载时调用；该 Canvas 与 PNG 导出 Canvas 分开。
}
```

接入示例：cancelBurstRef.current = burstBling(blingCanvasRef.current)；卸载清理：useEffect(() => () => cancelBurstRef.current?.(), [])。调用前确认 canvas ref 非空。
