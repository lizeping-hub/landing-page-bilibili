小电视保持透明背景。网页版本只做尺寸与编码压缩，原始生成文件保留于生成工具目录。七张压缩插画均已放入项目，不依赖生成工具目录运行。三组创作者复用相应兴趣插画，通过作品标题、介绍和状态构成独立示例。

短片分为科技研究所、音乐现场、城市日常三个四秒场景。背景缓慢推移，小电视和像素信号作为独立前景层，段落末尾交叉淡入下一场景。成片随仓库交付，浏览器无需现场编码。

图标和简化小电视标识为项目内 SVG 路径；档案为项目内 Canvas 版式；中文采用系统字体，无远程字体依赖。没有引入第三方视频、头像或站外跟踪服务。

维护脚本：

```sh
# 需要 Pillow；源目录包含上表列出的七张原图。
python scripts/prepare-assets.py /path/to/generated-originals

# 可选：重新生成短片。需要 Pillow 和 imageio-ffmpeg。
python -m pip install Pillow imageio-ffmpeg --target tmp/video-runtime
python scripts/make-film.py
```

网站运行和 GitHub Pages 构建不依赖 Python、生成工具或原始 PNG。
