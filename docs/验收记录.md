## 修正的问题

首次验收发现 HTML 图片尺寸影响卡片比例，已统一补充 height:auto；收敛小桌面的雷达圆环和手机档案圆环，消除横向溢出；将作品上的装饰播放图标改为实际可用的点赞控件；重新探索同时清除临时弹幕、更新地址并恢复首屏焦点；支持先清空宣言再输入新内容。

## 发布前需要继续验证

- 真实 GitHub Pages 域名下的 Actions 部署、HTTP 缓存及更新行为；当前只有配置和本地项目路径模拟。
- 指定 10Mbps、100ms、关闭缓存条件下的 LCP、CLS、实际交互 INP，以及持续滚动帧率。当前只确认资源预算，没有将性能目标当作测量结果。

- Chrome、Safari 和真实手机的最终浏览复核。

减少动态效果的分支、输入法保护、视频失败回退和卸载清理已实现并检查源码，但本次未通过真实设备操作覆盖上述场景。
